# IntervAI Pro

منصة مقابلات تجريبية بالذكاء الاصطناعي — تدعم **العربية والإنجليزية**.

**إعداد:** عائشة ناصر · الهندسة الكهربائية والإلكترونية · جامعة طرابلس
**إشراف:** د. نوري بنبارة

---

## كيف يعمل

```
السيرة الذاتية ─┐
                ├─► استخراج المهارات ─► حساب الفجوة ─► توليد الأسئلة ─► مقابلة تكيّفية
وصف الوظيفة  ──┘                                        (بوابة جودة)      (وكيل ReAct)
```

1. **الاستخراج** — مهارات تقنية وناعمة ولغات، من السيرة والإعلان.
2. **الفجوة** — مقارنة دلالية (`all-MiniLM-L6-v2`) بعتبة `0.6` مُعايَرة على
   بيانات فعلية: المهارات الموجودة تسجّل 0.89–1.00 والناقصة 0.25–0.49.
3. **الأسئلة** — ٦ على الفجوة و٤ على الموجود، وكل سؤال يمرّ ببوابة جودة
   **يحسبها الكود لا النموذج**.
4. **المقابلة** — وكيل يقيّم كل إجابة ويقرّر: تعمّق، أو انتقل، أو اتبع خيطاً
   ذكره المرشح.

## اللغة

تُكتشف لغة السيرة تلقائياً، **ويستطيع المستخدم تجاوز ذلك** — مهندس بسيرة
إنجليزية قد يفضّل مقابلة عربية. أسماء التقنيات تبقى بحروفها اللاتينية
(`Kubernetes` لا «كوبرنيتس») لأن طبقة القياس تطابقها بتلك الصيغة.

## قرار تصميمي

**النموذج يكتب، والكود يقيّم.** حين سُمح للنموذج بتقييم أسئلته، مرّت البوابة
٨ من ٨ وكل درجة `1.00` — بلا تمييز إطلاقاً (self-preference bias). بعد نقل
الحساب إلى كود حتمي، اتّباعاً لـ Nema & Khapra (EMNLP 2018)، صار المدى
`0.30–1.00` والبوابة ترفض فعلاً.

## التشغيل محلياً

```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .env   # ثم املئي القيم بصيغة KEY=value
streamlit run app.py
```

## الإعداد

يقرأ التطبيق من متغيّرات البيئة، فيعمل محلياً بـ `.env` وعلى Streamlit Cloud
بـ Secrets، بلا اختلاف في الكود:

| المتغيّر | الوصف |
|---|---|
| `FIREWORKS_API_KEY` | مفتاح Fireworks AI |
| `DB_HOST` · `DB_PORT` | خادم MySQL ومنفذه |
| `DB_NAME` · `DB_USER` · `DB_PASSWORD` | بيانات الاتصال |
| `DB_SSL_CA` | `ca.pem` — لمزوّدي الخدمة الذين يفرضون TLS |

بدونها يعود إلى `localhost` الافتراضية.
